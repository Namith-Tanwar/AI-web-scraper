# AI Web Scraper with Local LLM

A full-stack AI-powered web scraping application that scrapes dynamic websites, cleans the content, and uses a **local LLM (Llama 3.1 via Ollama)** to extract structured data.  
The backend is built with **FastAPI**, and the frontend uses **React + TailwindCSS**.

This project runs **fully locally** — no paid APIs required.

---

## 🚀 Features

- Dynamic website scraping using Playwright
- HTML body extraction and cleaning with BeautifulSoup
- Chunking system for LLM-friendly input
- Local AI extraction using Ollama (Llama 3.1)
- FastAPI backend API
- React + TailwindCSS frontend
- Structured data extraction from any website

---

## 🛠️ Tech Stack

### Backend
- Python  
- Playwright  
- BeautifulSoup4 + lxml  
- LangChain + Ollama  
- FastAPI  

### Frontend
- React (Vite)  
- TailwindCSS  

### LLM
- Ollama (Llama 3.1)
